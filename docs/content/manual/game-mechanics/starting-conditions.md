# Manual: Starting conditions and difficulty

## Remembered player count

The New Game player count can be two through eight players or Random. If a save contains an invalid remembered selection, the game uses its actual player count as the new selection when valid, otherwise the five-player default. Invalid selections in the local settings file also use the five-player default. This recovery does not change the players in the loaded game.

## Starting Buildings

Starting colonies receive buildings from a configured priority list. The game checks that list in order, adds each building the colony is allowed to have, and skips buildings that are unavailable or unsuitable for the race, government, climate, or population.

The maximum number of added buildings depends on the starting civilization:

| Starting civilization | Maximum added buildings |
| --- | ---: |
| Pre-warp | 3 |
| Average | 5 |
| Post-warp | 5 |
| Advanced | 9 |

Population can reduce this number further. Before adding another building, the colony's population must be greater than one and a half times the number already added, rounded down. The Capitol is handled separately and does not count toward this limit.

The list also skips buildings that would not have an effect. For example, environmental buildings are skipped for Tolerant races, food buildings are skipped for Lithovores, and morale buildings are skipped for Unification governments. The exact priority list and civilization caps can be changed by mods.

## AI Production Bonuses

Difficulty changes the food, production, research, and tax income generated by AI-controlled colonies. The built-in bonuses per working population unit are:

| Difficulty | Food | Production | Research | BC income |
| --- | ---: | ---: | ---: | ---: |
| Tutor | -0.25 | -0.5 | -0.5 | 0 |
| Easy | 0 | 0 | 0 | 0 |
| Average | +0.25 | +0.5 | +0.5 | +0.25 |
| Hard | +0.5 | +1 | +1 | +0.5 |
| Impossible | +1 | +2 | +2 | +0.75 |

These values are accumulated across the workers performing each job and then rounded when the colony total is calculated. Fractions are not rounded separately for every population unit, so the visible result can depend on how many population units perform the job.

Difficulty also affects other AI decisions and game events. This table covers only the direct colony-output and income bonuses.
