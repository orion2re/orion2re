## Imported 1.50 manual and patch work

This manual was originally developed for the MOO2 1.50 patch. Its historical
material provided a detailed compatibility reference for the Orion2 Redone
manual, but it does not by itself describe current behavior.

The following credits are retained from that work:

- Darza, for his invaluable contribution to the 1.50 patch project.
- Lord Brazen, for his 1.40 patch, which was incorporated into the 1.50 patch.
- Andrey Tyukov, for fixes studied and incorporated by the 1.50 project.
- Dmitry Yulmukhametov, the author of the original OCL.
- Nirran, for his work on OCL Improved, which provided information used by the
  1.50 project.
- TF8, for the map-generation tool that provided information about game data
  structures.
- Grig De Griz, for the MoO2 Workshop editor suite used to update help text and
  images.
- Epirasque, for work on Lua code and scripts.
- All users who reported bugs, shared design suggestions, and offered other
  advice that helped polish the patch.
- The MOO2 1.50 Project team, for the patch and the manual from which this
  documentation developed.

## Orion2 Redone restoration

Orion2 Redone is the work of the contributors to the orion2re restoration effort.
Thanks go to everyone who contributed implementation, documentation, testing,
