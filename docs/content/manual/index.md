# Manual

This is the player manual for Orion2 Redone. The project restores Master of Orion II as a native application for Windows, macOS, and Linux while retaining and extending fixes and features from the unofficial 1.50 patch.

The MOO2 1.50.26 manual remains the foundation of this manual, so its established organization and useful detailed explanations are retained. Information presented as current describes Orion2 Redone. Historical notes identify behavior or configuration that applies only to 1.50.

## Contents

- [About Orion2 Redone](overview/introduction.md): introduction, current features, and compatibility.
- [User-facing changes](user-facing-changes/index.md): interface, gameplay, and build queues.
- [Using mods](legacy-modding/index.md): installing, enabling, disabling, and troubleshooting mods and configuration, including the packages supplied with Orion2 Redone.
- [Game mechanics](game-mechanics/index.md): formulas and detailed subsystem behavior.
- [Advanced tools](advanced-tools/debugger.md): optional tools for testing and experimentation.
- [Reference](reference/index.md): keyboard shortcuts and acknowledgements.
